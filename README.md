# Convolution Neural Network using TensorFlow

## Overview

This project demonstrates the basic convolution operation used in Convolutional Neural Networks (CNNs) using TensorFlow.

The notebook loads an image, preprocesses it, applies a convolution filter (kernel), and visualizes the output feature map.

## Features

- Load an image
- Resize and preprocess the image
- Apply convolution using TensorFlow
- Display convolution output
- Understand the fundamentals of CNNs

## Technologies Used

- Python
- TensorFlow
- NumPy
- Matplotlib
- Google Colab

## Files

- `Convolution_Neural_Network.ipynb` – Main notebook
- `Ganesh.jpg` – Sample input image

## Learning Outcomes

- Basics of Convolution Neural Networks
- Image preprocessing
- Convolution operation
- Feature extraction
